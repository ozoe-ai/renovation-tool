# 担当者別保存の反映と確認

保存再試行対応版の最新手順・検証結果は `outputs/SAVE_FIX_REPORT.md` を参照してください。現在のアプリは `outputs/Code.gs` の `quote-export-v2` 版と組み合わせて反映する必要があります。

アプリの `/api/export-quote` は、既存のGAS Webアプリへ保存を依頼します。ローカルコードの変更だけでは、公開済みGASの保存先は変わりません。

## 反映

1. 現在デプロイ中のGASのソースとバージョンを控えます。
2. 現在利用している形式に対応する `.gs` の変更を反映します。テンプレートコピー形式は `quote-export-template-copy-fixed.gs`、その他の既存版はそれぞれ同名ファイルです。別の形式へ差し替えないでください。
3. 保存先の変更点は `assigneeFolder_` と、その戻り値を保存先に使う呼び出し部分です。既存のテンプレートID・出力形式・ファイル名・シークレットの設定を維持します。
4. 既存のWebアプリのデプロイを新しいバージョンへ更新し、同じURLを維持します。アプリ側も今回の変更を反映します。

この作業ではGASの公開更新と実Driveへのファイル作成を実施していません。

## 仕様

- 新規案件は案件一覧で選んだ有効な個人のIDと名前を保持します。「全件」「担当者全員」だけでは新規作成できません。
- 一覧フィルターは案件の担当者情報を書き換えません。途中の「新規作成」は最初の新規作成時に選んだ担当者を引き継ぎます。
- 保存先は `建設事業部 見積／担当者名`。直下の同名フォルダを再利用し、検索と作成をスクリプトロックで排他制御します。
- 既存の複数担当案件ではIDをすべて維持し、先頭IDの担当者のフォルダを保存先とします。旧案件の名前は既存の担当者データから補い、次の案件保存で保持します。
- 既存ファイルは移動・削除しません。未設定の旧案件は保存先を推測せず、エラーを表示します。
